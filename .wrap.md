# wrap configuration — shape

## Canonical locations

- index: `fixtures/README.md` — the "What is in it" table must match
  `fixtures/*.md`, ⚠️ **and so must the result lines under it**: those are what
  drift, because they read as facts and nobody re-runs the measurement
- lessons: `CLAUDE.md`, under `## Design decisions worth not re-litigating`
- skills: this repo *is* a skill; operational lessons go in `skills/shape/SKILL.md`
- decisions: no ADR directory. A decision lives in `CLAUDE.md` under
  `## Design decisions worth not re-litigating`, phrased as the trap plus the
  instance that produced it.
- journal: none. `CHANGELOG.md` under `## Unreleased`, dated per increment.
- entry point: `CLAUDE.md`, `## State — what is open`, under `### Start here`
- measurements: `skills/shape/references/calibration.md` — every number, with
  its corpus size, its date and its limits
- tracker: none. An open item is a line in the entry point, explicitly marked
  as not ticketed with the reason.

## Verification commands

- blocking: `just lint` — `markdownlint '**/*.md' --ignore node_modules`
- blocking: `just check-versions`
- advisory: `just check-fixtures` — ⚠️ exits **1** whenever *any* check returns
  3 (NOT RUN), not only a mermaid one, so a clean corpus on an underequipped
  machine still exits non-zero. Read the counts, not the status: "N failure(s)"
  is the blocking number, "N not run" is not.

## Disposable zones

- `.DS_Store` anywhere — gitignored
- `.impeccable/` — gitignored tooling state
- ⛔ `runs/` is **not** disposable. It is gitignored, and it holds
  un-reproducible ledger entries. Never clean it.

## Commit conventions

- format: `<type>: <the conclusion, lowercase>`
- ⭐ the subject states what was found, not what was done — "blocks opened does
  not measure locate cost", not "update calibration notes"
- no `Claude` signature, no generated-with footer

## Notes — what a wrap of this repo gets wrong

- **`SKILL.md` has no length ceiling any more.** The 🛑 150-line rule was
  ⛔ withdrawn 2026-09-01: never measured, and a line is a wrap artifact at 80
  columns. Do not reinstate a `wc -l` check in Seiso — what should replace it,
  if anything, is open in `CLAUDE.md` under `### Start here`.
- **The docs are layered and disagree on purpose.** `docs/shape-brief.md` is the
  source brief, `docs/shape-spec-v1.1.md` the amendment in force, `SKILL.md` the
  executing protocol. ⛔ Never reconcile the brief by rewriting it — supersede in
  place with a dated ⛔ retraction, so a reader arriving with the old claim can
  recognise it.
- **A measurement is reconciled in four places at once**, and the summary lines
  are what get missed: the `## State` entry point, `references/calibration.md`,
  `fixtures/README.md`, and the acceptance table in `SKILL.md` §5. A gate table
  row is the most expensive miss — it is the one Claude executes.
- **Never edit `SKILL.md` while shaping this repo's own docs.** The install is a
  symlink, so the protocol changes while it is running.
- **Two of the verification commands cannot run inside an agent's command
  sandbox, and they fail in a way that looks like a finding.** `check-render.sh`
  drives headless Chrome, which dies on `bootstrap_check_in … Permission denied`
  under seatbelt, and `git fetch` / a GPG-signed `git commit` die on their own
  IPC. ⚠️ So `just check-fixtures` inside the sandbox reports NOT RUN on every
  mermaid arm — a statement about the sandbox, not about the corpus. Run the
  checks and the publication outside it, and read a NOT RUN there as unproven.
